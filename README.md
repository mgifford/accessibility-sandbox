# Accessibility sandbox

Small, testable web accessibility experiments:

- [Visually hidden content](https://mgifford.github.io/accessibility-sandbox/hidden/): CSS, skip links, focus, zoom, and screen-reader behaviour.
- [Disabled and inactive controls](https://mgifford.github.io/accessibility-sandbox/disabled/): visual treatment, dark mode, native `disabled`, `aria-disabled`, `readonly`, `inert`, and validation alternatives.
- [AI Generated Reports](https://mgifford.github.io/accessibility-sandbox/ai-report): what people hope AI will be able to do. 

Each experiment documents what it demonstrates, how to test it, and what its evidence does not establish.
